## 📌 Overview

Track & Thrive is an interactive Power BI dashboard developed to analyze e-commerce business performance. The dashboard provides insights into sales, orders, customers, deliveries, returns, and warehouse operations, helping stakeholders make data-driven business decisions.

## 🛒 Business Problem

E-commerce businesses generate large volumes of transactional and operational data. Without an interactive reporting system, monitoring sales performance, customer behavior, delivery efficiency, and warehouse operations becomes challenging.

## 💡 Solution

Developed an interactive Power BI dashboard that provides:

- Sales performance analysis
- Customer insights
- Order and delivery tracking
- Returns analysis
- Warehouse performance monitoring
