## 📌 Overview

LitLens is an interactive Power BI dashboard designed to analyze global reading trends, book preferences, genres, publishers, and reader engagement. The dashboard transforms book-related data into meaningful visual insights to support data-driven analysis.

## 📖 Business Problem

The publishing industry generates extensive data on books, genres, authors, publishers, and reader preferences. Without effective visualization, identifying reading trends and understanding user behavior becomes difficult.

## 💡 Solution

Developed an interactive Power BI dashboard that provides:

- Genre-wise analysis
- Book popularity trends
- Publisher insights
- Reader preferences
- Reading pattern analysis
