# 🐾 Echo of the Voiceless

## 📌 Overview
Echo of the Voiceless is an interactive Power BI dashboard developed to analyze animal welfare data, including rescue, adoption, and related trends. The dashboard helps transform raw data into meaningful visual insights for better decision-making.

## 🛠️ Tools & Technologies
- Power BI
- Power Query
- DAX
- Microsoft Excel

## 📊 Dashboard Features
- KPI Cards
- Interactive Slicers
- Drill-through Pages
- Bar Charts
- Pie Charts
- Maps
- Trend Analysis

## 🎯 Key Insights
- Analyzed rescue and adoption trends.
- Visualized data using interactive dashboards.
- Created meaningful KPIs for decision-making.
